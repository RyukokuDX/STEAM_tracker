# プロジェクト要件定義書

---

### 1. プロジェクトの目的

管理者が認可した物品以外は処分する。そのサポートとなるサービスを作成することがこのプロジェクトの目的です。

---

### 2. 利用者と役割

| 役割       | 対象   | 主な権限・操作                                                                                                      |
| :--------- | :----- | :------------------------------------------------------------------------------------------------------------------ |
| **管理者** | 教職員 | ・追加された登録情報を通知で受け取る<br>・全登録物品を閲覧・操作する<br>・延長申請を許可/拒否する                                                       |
| **利用者** | 利用者 | ・物品を登録する<br>・リマインダーを受信する<br>・延長申請を管理者に申請する|

---

### 3. 主要なユースケース

#### 【ユースケース1：物品登録】

**アクター**: 利用者

**前提条件**: 利用者がスチームコモンズに物品を置いている

**基本フロー**:
1. 利用者は、システムへのアクセス方法を確認する
2. 利用者は、物品登録機能にアクセスする
3. 利用者は、以下の情報を提供する：
   - 所有者情報（氏名、団体名）
   - 明け渡し日（物品を撤去する予定日）
   - 物品の写真（設置場所がわかるもの）
   - 規約への同意
4. システムは、登録情報を保存する
5. システムは、登録完了を利用者と管理者に通知する

**事後条件**: 物品がシステムに登録され、管理対象となる

---

#### 【ユースケース2：明け渡し日リマインダー】

**アクター**: システム、利用者

**前提条件**: 物品が登録されている

**基本フロー**:
1. システムは、登録された明け渡し日を定期的に監視する
2. システムは、明け渡し日が近づいた物品を検出する
3. システムは、該当する利用者にリマインダー通知を送信する
4. システムは、管理者にも通知を送信する

**事後条件**: 利用者が明け渡し日を認識し、対応を開始できる

---

#### 【ユースケース3：延長申請】

**アクター**: 利用者、管理者

**前提条件**: 物品が登録されており、利用者が延長を希望している

**基本フロー**:
1. 利用者は、延長申請機能にアクセスする
2. 利用者は、延長理由と希望期間を入力する
3. システムは、申請情報を記録する
4. システムは、管理者に延長申請を通知する
5. 管理者は、申請を承認または却下する

**事後条件**: 承認された場合、明け渡し日が更新される

---

#### 【ユースケース4：撤去完了処理】

**アクター**: 管理者

**前提条件**: 物品が実際に撤去されている

**基本フロー**:
1. 利用者は、物品を撤去する
2. 利用者は、管理者に撤去完了を報告する
3. 管理者は、撤去を現地で確認する
4. 管理者は、システム上で撤去完了処理を実行する
5. システムは、該当データをアーカイブに移動する

**事後条件**: 物品データが記録として保存され、管理対象から外れる

---

### 4. システムの制約条件

#### 業務上の制約
- 明け渡し日の最終期限は、年度末とする
- 延長申請の回数や期間には制限を設ける可能性がある
- 撤去完了の確認は、管理者の現地確認を必須とする

#### 技術的な制約
- 利用者は、インターネット接続可能なスマートフォンまたはPCを持っている必要がある
- システムへのアクセスには、メールアドレスが必要

#### 対象範囲
- 本システムは、スチームコモンズ内の物品のみを対象とする
- 共用備品や消耗品は対象外とする

---

### 5. 用語集

| 用語 | 定義 |
| :-- | :-- |
| **明け渡し日** | 利用者が物品を撤去する予定日。最終期限は年度末。 |
| **撤去完了** | 管理者が現地で物品の撤去を確認し、システム上で完了処理を行った状態。 |
| **アーカイブ** | 撤去完了した物品のデータを記録として保存すること。将来の参照や分析のために保持される。 |
| **リマインダー** | 明け渡し日が近づいたことを利用者に通知するメッセージ。 |
| **延長申請** | 利用者が明け渡し日を延期したい場合に管理者に提出する申請。 |
| **管理者** | スチームコモンズの運営を担当する教職員。物品の管理と延長申請の承認を行う。 |
| **利用者** | スチームコモンズに物品を置く学生や団体。 |
