# LINE Bot仕様書

> 本書は現行実装に準拠する。最終更新: 2026-11-05

## 1. 目的
本Botは、スチームコモンズ物品管理システムの運用補助を目的とし、管理者のみが利用する通知・申請管理Botです。
LINE への送信は `line_bot`（リマインド・登録通知）と `extend_form`（延長申請・許可/却下）の 2 つの GAS プロジェクトが行います。

## 2. 主な機能

| 機能 | 実装 | 内容 |
|:---|:---|:---|
| 明け渡しリマインド | `line_bot` / `handoverDayRemind` | 毎日 9 時台に実行。明け渡し 3 日前・当日の物品について、利用者へメール、管理者へ LINE を送る。期限超過の物品には利用者へ毎日メールを送り、管理者へ 1 日 1 通のまとめ LINE を送る |
| 物品登録通知 | `line_bot` / `registerNotify` | `stuffForm` からの依頼（`doPost`）を受けて管理者へ送る |
| 延長申請通知 | `extend_form` / `notifyExtensionRequest` | 延長申請を「許可」「却下」ボタン付きで管理者へ送る |
| 延長申請の許可/却下 | `extend_form` / `approveRequest`・`rejectRequest` | LINE Webhook でボタン操作を受け取り、明け渡し日の更新と利用者へのメール通知を行う |

## 3. 利用者と権限

| 役割       | 主な操作・権限                       |
|:-----------|:-------------------------------------|
| 管理者     | 通知の受信、延長申請の許可/却下       |

送信先・Webhook の受付対象は、スクリプトプロパティ `USER_ID` の管理者 1 名。

## 4. メッセージ仕様

表記の統一ルール:
- 氏名・団体名は「{氏名}（{団体名}）」とし、団体名が空欄なら「{氏名}（団体名未入力）」とする。
- 日付は「yyyy/MM/dd」（例: 2026/07/29）とする。

- 物品登録時：「物品登録」（写真、「{氏名}（{団体名}）」、「明け渡し日：{日付}」を表示。明け渡し日を受け取れなかった場合は「未取得」）
- 明け渡し日 3 日前：「[リマインド]{氏名}（{団体名}）の明け渡し日まであと3日です。」
- 明け渡し日当日：「[リマインド]{氏名}（{団体名}）の明け渡し当日です。」
  - 利用者へのメール送信に失敗した場合は、本文に「（メール送信に失敗しました。{理由}）」を付記する。
- 期限超過（毎日 1 通）：「[期限超過]明け渡し日を過ぎている物品が{件数}件あります。」に続けて、超過日数の多い順に「・{氏名}（{団体名}） 明け渡し日 {日付}（{n}日超過）」を最大 30 件列挙する。メール送信に失敗した物品には「（メール送信失敗）」を付記する。
- 延長申請時：「延長申請 No.{行番号}」（写真、「{氏名}（{団体名}）」、「希望延長日：{日付}」、「許可」「却下」ボタン）
- 許可/却下後：「延長申請No.{行番号}を {日付} まで許可しました。」/「延長申請No.{行番号}を却下しました。」

## 5. 技術構成

- LINE Messaging API（Push API、Webhook）
- Google Apps Script（GAS）
- Google スプレッドシート（items シート）

LINE チャネルの Webhook URL には `extend_form` の Web アプリ URL を設定する。

## 6. エラー・例外処理

- LINE 送信は最大 3 回まで再試行する（4xx は再試行しない）。失敗はログに記録する。
- 必須スクリプトプロパティ・シートが無い場合は起動時に例外で停止する。
- 延長申請・Webhook の不正な id・日付・非 active 行はログに記録してスキップする。

## 7. リマインド通知の判定と運用

- 実行関数：`handoverDayRemind`（日次の時間主導トリガー、9時台）。トリガーは `setupReminderTrigger` を手動実行して作成する。
- 対象：items シートで status が active の行。
- 残り日数は F列（handover_on）と実行日から算出する。F列から算出できない場合のみ G列（days_until_handover）の数値を使う。G列の空欄は 0 日として扱わない。
- 残り日数が 3 日・0 日の行について、登録者へ Gmail、管理者へ LINE を送信する（メール失敗時は LINE 本文に失敗理由を付記）。
- 期限を過ぎた行には、登録者へ毎日「STEAMコモンズ 明け渡し期限超過のお知らせ」メールを送り、管理者へは全件を 1 日 1 通の LINE にまとめて送る。アーカイブされるか延長が許可されるまで続く。
- 終了時に `summary=` ログ（rows / sent / overdueSent / skippedStatus / skippedDays / invalidDate / mailFailed / lineFailed）を出力する。
- status が空欄の既存行（status 管理導入以前の登録分）は `backfillActiveStatus` を一度実行して active に補完する。
- トリガーと運用上の注意は `docs/GAS_REQUIREMENTS.md` §4 を参照。

## 8. 延長申請フォームへの導線

- 登録完了の確認メール（stuffForm）に延長申請フォームの URL を記載する（stuffForm のスクリプトプロパティ `EXTEND_FORM_URL`）。
- 明け渡し 3 日前・当日のリマインドメールにも同フォームの URL を記載する（line_bot のスクリプトプロパティ `EXTEND_FORM_URL`）。
- 両プロジェクトとも同じキー名 `EXTEND_FORM_URL` で、GitHub Pages で公開している `extend_form/` の URL を設定する。
