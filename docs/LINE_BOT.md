# LINE Bot仕様書

## 1. 目的
本Botは、スチームコモンズ物品管理システムの運用補助を目的とし、管理者のみが利用する通知・申請管理Botです。

## 2. 主な機能

- 物品登録・撤去・延長申請を管理者に通知
- 管理者への延長申請・撤去完了報告の通知
- 年末度の一斉通知
- 申請受信時に該当フォームへ誘導する（リンクまたはボタンを送付）

## 3. 利用者と権限

| 役割       | 主な操作・権限                       |
|:-----------|:-------------------------------------|
| 管理者     | 申請承認/否認、通知送信、履歴確認     |

## 4. メッセージ仕様

- 物品登録時：管理者に「新規物品登録通知」
- 明け渡し日3日前・当日：管理者に「リマインダー通知」
- 延長申請時：管理者に「延長申請通知」
	- メッセージ内に延長申請フォーム（Apps Scriptで作成した独自フォーム）へのリンク（またはボタン）を含め、管理者が該当フォームへアクセスできるようにする
- 撤去完了時：管理者に「撤去完了通知」
- 年度末：管理者に「一斉通知」

## 5. 技術構成

- LINE Messaging API
- Google Apps Script（GAS）連携
- Apps Script（GAS）で作成した独自フォーム / スプレッドシート連携

## 6. エラー・例外処理

- 通知失敗時は管理者に再送・エラー通知
- 不正な申請・データはエラーメッセージ返信
