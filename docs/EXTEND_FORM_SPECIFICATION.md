# 延長申請フォーム仕様書

## 1. 概要
本仕様書では、スチームコモンズ物品管理システムにおける延長申請フォームの動作仕様を定義する。延長申請フォームは、利用者が撤去予定日の延長を申請するためのWebフォームであり、Apps ScriptとHTMLを用いて実装される。

実装: `extend_form/GAS/code.js`、`extend_form/index.html`

## 2. 主な機能

1. **延長申請フォームの提供**: 利用者がアクセスできる静的HTML + GAS fetch のWebフォームを提供する。
2. **物品一覧の取得**: メールアドレスをキーに、該当利用者の登録物品一覧を取得する（`getItemsByEmail`）。
3. **日付入力**: 延長希望日をカレンダーウィジェットで入力させる。年度末を上限日とする（`GetFiscalYearEnd`）。
4. **管理者への通知**: 申請送信時、管理者の LINE に許可/却下ボタン付きメッセージを送信する（`notifyExtensionRequest`）。
5. **管理者の許可/却下処理**: LINE postback から `approveRequest` / `rejectRequest` が呼ばれる。
6. **利用者への結果通知**: 許可/却下の結果を利用者にメールで通知する。

## 3. 入力項目

### ログイン画面
- **学籍番号**: 龍谷大学ドメイン（`mail.ryukoku.ac.jp`）のメールアドレスを生成するために使用。
- メールアドレスを基に管理シートから物品を参照する。

### 延長申請フォーム
- **物品リスト**: 団体名、物品名、現在の明け渡し日、延長希望日を表示する。延長したい物品の希望日を変更する。

## 4. 日付入力の制限

- 延長希望日の入力欄には、カレンダーウィジェットを使用し、利用者が選択できるようにする。
- カレンダーウィジェットには年度末（`GetFiscalYearEnd` で算出：4月以降は翌年3月31日、1〜3月は当年3月31日）を上限日として設定し、それ以降の日付は選択不可とする。
- サーバ側でも `YYYY-MM-DD` regex と `id` の範囲検証を行う。

## 5. 管理者への通知

- 申請送信後、管理者の LINE に画像 + 許可/却下ボタン付きの Flex Message を送信する。
- 通知内容には、申請ID（スプレッドシート行番号）、団体名、利用者氏名、延長希望日を含める。
- 許可ボタン押下 → `approveRequest`: スプレッドシートの該当行の `HANDOVER_ON` 列を更新し、利用者にメールで承認通知を送信する。
- 却下ボタン押下 → `rejectRequest`: 利用者にメールで却下通知を送信する。
- postback データは `action=approve&id={id}&date={newDate}` または `action=reject&id={id}` 形式。

## 6. 利用者への通知

- **フォーム送信直後**: ブラウザ上で「申請内容を確認後、メールにて通知いたします。」と案内文を表示する（`extend_form/index.html`）。
- **管理者による許可/却下後**: Gmail で結果メールを送信する（現状、フォーム送信直後の利用者宛メール送信は実装されていない。必要性は要検討）。

## 7. 申請内容の保存

- 申請内容は、管理者が許可した場合のみスプレッドシートの `HANDOVER_ON` 列に反映される。
- 却下の場合はスプレッドシートへの書き込みは行わない（申請自体の記録も残らない点は要検討）。

## 8. LINE Webhook（postback）受信

- `doPost` が静的HTMLからの fetch（`json.action` あり）と LINE Webhook（`json.events` あり）を判別してディスパッチする。
- Webhook は `LINE_WEBHOOK_TOKEN` クエリパラメータで認証する（未設定時は検証スキップ、本番環境では設定必須）。
- 送信元 `userId` が script property `USER_ID`（管理者）と一致する postback のみ処理する。
