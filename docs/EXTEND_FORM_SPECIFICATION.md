# 延長申請フォーム仕様書

> 本書は現行実装（`extend_form/index.html` / `extend_form/GAS/code.js`）に準拠する。最終更新: 2026-11-05

## 1. 概要
本仕様書では、スチームコモンズ物品管理システムにおける延長申請フォームの動作仕様を定義する。延長申請フォームは、利用者が明け渡し日の延長を申請するための Web フォームである。
画面は静的 HTML（`extend_form/index.html`）で GitHub Pages に公開し、処理は GAS Web アプリ（`extend_form/GAS/code.js`）が行う。送信先 URL は GitHub Actions の Secret `EXTEND_GAS_URL` から埋め込む。

## 2. フォームへの導線
- 登録完了の確認メール（`stuffForm`、スクリプトプロパティ `EXTEND_FORM_URL`）
- 明け渡し 3 日前・当日のリマインドメール（`line_bot`、スクリプトプロパティ `FORM_URL`）

## 3. 画面と入力項目
1. ログイン画面
   - 学籍番号を入力する。`{学籍番号}@mail.ryukoku.ac.jp` をメールアドレスとして、items から物品を検索する。
   - 対象は、メールアドレスが一致し（大文字小文字は区別しない）status が `active` の物品のみ。
2. 申請画面
   - 物品ごとに写真・団体名・氏名と延長希望日の入力欄を表示する。初期値は現在の明け渡し日。
   - 全物品の延長希望日が入力されていないと送信できない。
3. 完了画面
   - 「申請内容を確認後、メールにて通知いたします。」と表示する。

## 4. 日付入力の制限
- カレンダーウィジェットで選択する。
- 下限は明日、上限は現在の明け渡し日が属する年度の末日（3 月 31 日）。
- 上下限の制限はフロントエンドのみで行い、サーバー側は日付形式（YYYY-MM-DD）のみ検証する。

## 5. 管理者への通知と承認
- 送信すると、表示された物品ごとに管理者へ LINE を送る（延長申請 No.{行番号}、団体名・氏名、希望延長日、「許可」「却下」ボタン）。延長希望日を変更していない物品も通知対象になる。
- ボタン操作は LINE Webhook（`extend_form` の `doPost`）で受け取る。スクリプトプロパティ `USER_ID` 以外からのイベントは無視する。
- 許可した場合: items の handover_on を希望延長日に更新し、利用者に「STEAMコモンズ 延長申請許可通知」メールを送り、管理者に処理結果を LINE で送る。
- 却下した場合: 利用者に「STEAMコモンズ 延長申請却下通知」メールを送り、管理者に処理結果を LINE で送る。
- 対象行の status が `active` でない場合、許可・却下とも処理しない。

## 6. 利用者への通知
- 申請受付時点ではメールを送らない。
- 管理者の許可・却下時にメールで結果を通知する。

## 7. 申請内容の保存
- 申請内容そのものは保存しない。管理者が許可した場合のみ、items の handover_on 列に反映される。
